# Career RAG Agent 优化说明

## 本轮新增能力

1. 证据绑定建议
   - 匹配分析不再只返回字符串建议，而是返回 `suggestion_cards`。
   - 每条建议包含技能、建议文案、支撑证据 ID、证据预览、置信度和风险等级。
   - 面试时可以说明：简历可写内容必须绑定 verified 履历证据。

2. 防幻觉风险提示
   - 对缺少证据的必备技能和加分技能生成 `risk_flags`。
   - 必备技能缺证据时禁止写成“已掌握”；加分技能缺证据时只能放到缺口或学习计划。
   - 这比单纯依赖 Prompt 更可控，属于业务层 guardrail。

3. 人工反馈与 Bad Case 闭环
   - 新增 `match_feedback` 数据结构和 API。
   - 支持记录准确性、问题类型、反馈说明和修正建议。
   - 问题类型覆盖证据不相关、漏匹配、幻觉、分数错误、引用错误等。

4. 离线评测汇总
   - 新增 `evals/match_feedback_eval.py`。
   - 可将人工反馈汇总为准确率代理指标、问题分布和可处理 Bad Case。
   - 可和已有检索评测脚本组成持续迭代链路。

5. Agent 轨迹评测
   - 新增 `evals/agent_eval.py` 和 `agent_golden_set.json`。
   - 支持评估工具选择、工具召回、调用顺序、最大调用次数、工具异常和最终答案规则。
   - 离线模式可用于 CI，live 模式可接当前 Agent 做端到端回归。

## 面试讲法

这个项目不是只做了 RAG 问答和 Agent 调工具，而是补了可追踪、可校验和可评测的工程闭环。系统在岗位匹配后会把可写入简历的建议绑定到已确认履历证据，缺少证据的能力进入风险提示，避免模型把 JD 里的要求直接编进候选人经历。同时，用户可以对匹配结果做人工反馈，反馈会沉淀为 Bad Case，用于后续扩展 golden set、调整检索参数、优化 Prompt 和工具策略。Agent 评测侧则从工具选择、调用顺序和答案规则三个维度做回归检查，防止改 Prompt 或工具描述后引入行为退化。

## 简历精简版

- 面向求职岗位匹配场景实现 RAG + Agent 应用，覆盖 JD 管理、履历证据、匹配分析、简历定制、投递记录、资料库问答和智能助手等模块。
- 构建 PDF/Markdown/TXT 文档解析与混合检索流程，支持 Chroma 向量检索、BM25 中文关键词召回、RRF 融合排序、相似度阈值过滤与 Rerank 精排。
- 基于 LangChain Tool Calling 封装岗位查询、履历证据、匹配分析、简历定制和资料库问答等业务工具，实现多步求职任务自动执行。
- 设计防幻觉校验机制，将简历建议绑定到 verified 履历证据，对缺少证据的岗位技能生成风险提示，避免模型编造候选人经历。
- 补充 Agent 记忆、运行审计、人工反馈和离线评测体系，记录工具调用链路、Bad Case、检索指标、工具选择准确率和匹配质量反馈，支持持续优化。
